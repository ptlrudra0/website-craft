# Validate the result

Before delivery: screenshots at phone/tablet/desktop; headings and page title; no horizontal overflow; useful link targets; truthful demo labels; keyboard focus; actual buttons/forms; image failure fallback; reduced motion; readable contrast; crop/text collisions. Inspect the pixels and fix material issues.

If you cannot run a check, say so. Automated checks are narrow evidence, not a claim of WCAG certification or universal quality. A screenshot proves a frame, not that all motion or real-device interactions work. Check native agent setup separately from a generated site's browser output.
