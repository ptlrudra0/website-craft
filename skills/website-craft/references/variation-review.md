# Same brief, different directions

Hold the business, audience, facts and primary action fixed. Build two alternatives from the same brief, not two unrelated industries. Compare:

| Dimension | What to inspect |
|---|---|
| Information order | What does the reader learn first, and why? |
| Composition | Split narrative, index, poster, sequence or another content-led structure? |
| Typography | Roles, scale, measure and hierarchy, not merely a font swap |
| Imagery | Real evidence, conceptual illustration or text-led; crop and focal point |
| Interaction | Does the business task justify this control/motion? |
| Mobile | Does the hierarchy recompose without losing the action? |

If only colour changes, reject the pair as evidence of variety. If a user provides a strict reference, respect it instead of manufacturing differences. Record the decision in that project's local notes without storing unrelated client data. The included demo variants are authored examples of this review, not evidence of repeated autonomous agent runs.
